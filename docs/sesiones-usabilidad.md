# Sesiones con cinco participantes

Usar únicamente cuentas y fondos de prueba. Solicitar consentimiento antes de grabar; registrar observaciones sin PIN, claves ni datos personales. Ejecutar en el dispositivo habitual de cada persona y sin asistencia inicial.

| Tarea | Evidencia a registrar |
| --- | --- |
| Empezar y escuchar instrucciones | Encuentra el audio, comprende la cuenta de prueba, elige perfil sin selección accidental al escuchar. |
| Crear una cuenta y un PIN | Completa y borra dígitos, comprende la repetición y qué ocurre si olvida el PIN. |
| Ajustar un reparto | Explica cuánto iría a cada espacio si recibe S/100; modifica una barra con el dedo. |
| Resolver un fallo de red | Entiende el mensaje y el siguiente paso, conserva su configuración y reintenta sin ayuda. |
| Recargar durante la confirmación | Recupera el intento, reconoce cuándo esperar y cuándo continuar. |
| Continuar a su cuenta | No llega al dashboard antes de guardar correctamente sus reglas y perfil. |

Anotar por participante P1–P5: dispositivo/navegador, hora de inicio y finalización, tiempo por tarea, pausas de red por separado, errores, solicitudes de ayuda y frase que interpretó incorrectamente. Pedir que explique el reparto con sus propias palabras; no sugerir la respuesta.

Repetir una sesión con teclado y lector de pantalla; en móvil comprobar VoiceOver/Safari y TalkBack/Chrome. Escuchar el PIN debe leer instrucciones, nunca los dígitos ingresados. Confirmar que Detener audio no reproduce una respuesta tardía.

Criterio para informar duración: publicar mediana y rango observados con las cinco personas, separando esperas de red y tareas que no pudieron completar. No convertir un tiempo medido con automatización en una promesa para usuarios.
